# Opus 5 流式稳定性与自动续写实施计划

## 目标

修复生产中三类可复现问题：上游 HTTP 200 空流、少量输出后提前 EOF、Thinking 重复喷发；同时增加可灰度开启的纯文本 `max_tokens` 自动续写。

## 已确认事实

- Kiro 会返回 HTTP 200 但没有任何语义事件，RS 当前在两次尝试后返回 502。
- 长历史窗口比 Fork 后的新窗口更容易触发空流，说明故障与历史 payload 相关，不是固定 token 硬限制。
- 生产日志在 `2026-07-25T04:38:00Z` 和 `05:37:39Z` 记录了 Thinking 复读熔断；后者是同一 24 字节单元重复 16 次。
- 当前熔断后伪装成 `max_tokens`/成功，会掩盖上游退化，也可能错误触发自动续写。

## 行为边界

### 默认保持不变

- 自动续写默认关闭。
- 半截流恢复默认关闭。
- 上下文恢复默认关闭。
- 不改变提前 SSE 握手配置，不取消现有 1 秒首字路径。

### 永远禁止透明续写

- 已发出任何 `tool_use`。
- 上游空流、读错误、空闲超时、重复熔断、工具 JSON 错误、上下文超限或显式 API 错误。
- stop reason 不是 `max_tokens`。

### 自动续写规则

- 只处理纯文本 `max_tokens` 截断，最多续写配置次数，默认上限 3。
- 客户端只看到一条 Anthropic message；中间轮不发 `message_delta`/`message_stop`。
- 续写请求包含已经生成的正文，并要求只从断点继续。
- 对续写开头做最长后缀/前缀重叠消除，避免接缝复读。
- 汇总所有上游轮次 usage 和 credits。

## 客户影响

| 功能 | 默认 | 开启后的影响 |
| --- | --- | --- |
| Thinking 复读保护 | 开启 | 更早截断确定性复读；不会修改正常正文 |
| 自动续写 | 关闭 | 可能增加上游调用次数、总耗时和费用；首字延迟不变 |
| 半截流恢复 | 关闭 | 可能丢弃可疑短输出并重试，首字和费用可能增加 |
| 上下文恢复 | 关闭 | 可能裁剪旧历史，缓存命中下降且模型可能遗忘早期内容 |

## 实施顺序

1. 将重复熔断设为独立终态，禁止记为普通成功或触发自动续写。
2. Thinking 通道更早抑制确定性重复，正文通道保留现有保守阈值。
3. 增加续写请求构造、状态复用、接缝去重和 usage 汇总测试。
4. 接入实时流路径；非流式暂不自动续写，避免扩大行为面。
5. 在管理端增加开关、最大续写次数和明确风险提示。
6. 运行 Rust 定向/全量测试与管理端测试、构建。

## 验收标准

- Thinking 相同短单元重复时，不再无限输出，trace 记为 `upstream_repetition_guard`。
- 复读熔断不触发续写。
- 开关关闭时 SSE 字节序列与现状一致。
- 开关开启且纯文本 `max_tokens` 时，客户端只收到一个 `message_start` 和一个最终 `message_stop`。
- tool_use、空流及显式错误不会自动续写。
- 管理端配置可保存、重启后保留并正确回显。

## 实施结果

- Thinking 复读阈值调整为 4 次，正文仍保持 16 次的保守阈值。
- 复读熔断改为独立 `upstream_repetition_guard` 错误终态；客户端不再收到伪造的
  `max_tokens` 成功和 `message_stop`。
- 自动续写仅接受未启用 Thinking 的纯正文 `max_tokens`；Thinking 请求、tool_use、协议错误、
  上下文超限、读错误、idle timeout、空流或复读熔断时均禁止续写。
- `end_turn` 只有在“半截流恢复”灰度开关开启时才可进入短时窗判定。
- 续写保持原 `conversationId` 和 `agentContinuationId`，维持同一 Kiro 会话与 RS
  凭据粘性；续写轮清空图片、工具和工具结果。
- 续写接缝按前轮末尾 8 KiB 做 UTF-8 安全的最长后缀/前缀去重，避免常见的断点复读；
  该上限用于限制缓冲内存和额外等待时间，不尝试吞掉整篇长响应的从头重放。
- Anthropic `input_tokens/cache_*` 继续只反映客户端实际发送的请求，避免隐藏续写提示造成
  按输出长度增长的 token 注入；上游所有续写轮的 `output_tokens` 与 Kiro `credits` 累计统计。
- 管理端新增自动续写、最大轮数、半截流恢复和判定窗口配置；风险功能默认关闭，并明确提示
  可能增加上游调用次数、总耗时和费用。
- 提前 SSE 握手及 1 秒首字路径未改动。
